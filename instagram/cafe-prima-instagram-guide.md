## 4. リール台本 2本（撮影〜投稿まで）

### リール①「昼カフェ→夜バー」15秒

| 秒 | 映像 | テロップ（日／英） |
|---|---|---|
| 0-3 | 昼の明るい店内 → ランチの皿 | 昼はカフェ / Cafe by day |
| 3-7 | ランチのシズル（湯気・カット断面） | 京都・四条烏丸 / Shijo-Karasuma, Kyoto |
| 7-11 | 照明を落とすカット → カクテル注ぐ | 夜はバー / Bar by night |
| 11-15 | 乾杯 → ロゴ | 駅から1分 / 1 min from the station |

キャプション：④の夜バー文をそのまま使用。

### リール②「季節のスイーツ、できるまで」10秒

クリームを絞る→フルーツを乗せる→完成、の3カットのみ。BGMはトレンド音源。
テロップ：「今だけ / Only now」「京都 四条烏丸 / Kyoto」

## 5. 撮影ルール（スタッフ指示用・そのまま共有可）

```
【Instagram写真ルール】
1. 窓際の自然光で撮る。店内照明の下では撮らない（黄色くなる）。
2. 提供直前に撮る。湯気・照り・ソースの艶が命。
3. 角度は2枚必ず撮る：真上（俯瞰）と、斜め45度。
4. 背景を片付ける。おしぼり・伝票・他の皿は画角から外す。
5. 加工は明るさ＋10、彩度＋5まで。盛りすぎ厳禁（来店時のギャップがクレームになる）。
6. 撮った写真は当日中に共有アルバムへ。ファイル名は「日付_商品名」。
7. お客様が写り込む場合は必ず許可を取る。
```

## 7. 見るべきKPI（月次チェック）

| 指標 | 目安 | 意味 |
|---|---|---|
| リーチ（非フォロワー比率） | 60%以上 | 新規に届いているか |
| 保存数／投稿 | 30以上 | 「行きたい」と思われたか（最重要） |
| プロフィールアクセス | 週200以上 | 来店検討の手前まで来た人数 |
| DM予約件数 | 月10件以上 | 直接売上に繋がった数 |
| 投稿→Googleマップ経由来店 | 増減を追う | MEOとの相乗効果 |

**判断基準：保存数が伸びない投稿は写真が弱い。リーチが伸びない投稿はリール不足。**

## 8. やってはいけないこと

- 実物と違う加工（★最大のリスク。低評価口コミの原因）
- 価格を書かない投稿の連発（インバウンドは特に価格不明を嫌う）
- ハッシュタグ30個フルで毎回同じ（スパム判定）
- 日本語だけの投稿（外国人観光客の流入を丸ごと捨てている）
- 2週間以上の放置（アルゴリズム上、再浮上に時間がかかる）
