# Instagram運用スタート連絡（奥村さん・藤山さん宛）

作成日: 2026-09-20 / 対象: Café Prima

---

## A. LINEでそのまま送る文（第1報・短め）

```
奥村さん、藤山さん

お疲れ様です。
Café PrimaのInstagram、今月から運用の型を決めて回していきます。
お二人に担当をお願いしたいです。

【なぜやるか】
新規のお客様の入口が、今はGoogleマップとInstagramの2つです。
Instagramは「行きたい」と思わせる役割。
特に外国人のお客様は投稿を見て来店を決めるので、
日本語だけの投稿だと機会をまるごと捨てている状態です。

【お願いしたいこと】
・フィード投稿 週3本（火・金・日）
・リール 週1〜2本
・ストーリーズ 毎日1〜3枚

投稿文は日本語＋英語のセットを12本用意しました。
写真を差し替えて、そのままコピペで投稿できます。
ゼロから文章を考える必要はありません。

このあと詳しい手順を送ります。
不明点や「これは回らない」という部分があれば遠慮なく言ってください。
現場が回る形に調整します。

よろしくお願いします。
```

## B. 続けて送る詳細指示（コピペ用）

```
【Café Prima Instagram 運用ルール】

■ 担当分け（相談の上で確定したい）
・奥村さん：フィード投稿（週3本）＋ハイライト整備
・藤山さん：リール（週1〜2本）＋ストーリーズの声かけ
・ストーリーズは出勤者全員で1日1〜3枚

■ 投稿する曜日と時間
火：ランチ（パスタ/ピザ/肉サンド）→ 10:30〜11:00に投稿
木：リール（昼→夜の切り替え）→ 17:00〜18:30に投稿
金：夜バー訴求 → 17:00〜18:30に投稿
日：季節スイーツ or 誕生日プレート → 14:00前後に投稿

理由：その時間に「これからどこ行こう」と探している人に当てるためです。
深夜や早朝に投稿しても見られません。

■ 投稿文の型（毎回これ）
1行目：フック（20文字以内）
日本語本文 3行
（空行）
英語本文 3〜4行
（空行）
店舗情報
（空行）
ハッシュタグ 15〜20個

■ 文章について
日本語＋英語のセットを12本用意済みです。
・パスタ／ピザ／肉サンド／夜バー／誕生日プレート／秋スイーツ
・旬のタルト／周年／アクセス案内／雨の日／貸切／スタッフ紹介
写真を変えて使い回してOK。同じ文を2週間あけて再利用も問題なしです。

■ ハッシュタグ
ランチ用・夜バー用・スイーツ用の3セットを用意しています。
毎回2〜3個だけ入れ替えてください。
完全に同じものを3回連続で使うとスパム判定されます。

■ 写真の撮り方（ここが一番大事）
1. 窓際の自然光で撮る。店内照明の下は黄色くなるのでNG
2. 提供直前に撮る。湯気・照り・艶が命
3. 俯瞰と斜め45度、必ず2枚
4. おしぼり・伝票・他の皿は画角から外す
5. 加工は明るさ+10、彩度+5まで。盛りすぎ厳禁
   → 実物と違うと口コミで低評価になります。ここは絶対守ってください
6. 当日中に共有アルバムへ。ファイル名は「日付_商品名」
7. お客様の写り込みは必ず許可を取る

■ 月末に見る数字
・保存数／投稿：30以上（最重要。「行きたい」と思われた数）
・非フォロワーリーチ率：60%以上（新規に届いているか）
・プロフィールアクセス：週200以上
・DM予約件数：月10件以上

保存数が伸びない＝写真が弱い
リーチが伸びない＝リール不足
この2つで原因を切り分けます。

■ やらないこと
・実物と違う過剰な加工
・価格を書かない投稿の連発（特に外国人客は価格不明を嫌います）
・日本語だけの投稿
・2週間以上の放置
```

## C. 口頭で補足すること（ミーティング用メモ）

- **負荷は増やさない前提**：文章はすでに用意済み、撮影は営業中の数秒。新しい仕事を増やすというより、今までバラバラだったものを型にはめるだけと伝える。
- **成果は数字で見る**：感覚評価はしない。月末に保存数とDM予約件数だけ一緒に見る。
- **失敗はOK**：投稿が滑っても責めない。止まることだけが唯一のNG。
- **確認事項**：営業時間・住所の確定版、周年の数字（開店年）、秋の実メニュー名と価格。この3点が揃えば投稿文が完成形になる。
