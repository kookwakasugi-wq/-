# Instagram → Google最新情報 連携前提の投稿ルール（改訂版）

作成日: 2026-09-20 / 対象: Café Prima（四条烏丸）→ 後続でKyoto Prima Gojo（五条）

---

## 0. 前提が変わった点

Instagram投稿が自動でGoogleビジネスプロフィールの「最新情報」に反映される設定。
つまり**1回の投稿が、Instagram（SNS流入）とGoogleマップ（検索流入）の2箇所に同時に出る**。

これにより投稿の書き方が変わる：

| | Instagram | Google最新情報 |
|---|---|---|
| 見られ方 | 写真が先、文は後 | **文の冒頭80文字前後だけ表示** |
| ハッシュタグ | 効く | 効かない（文字列がそのまま出るだけ） |
| 英語の必要性 | 訪日客の発見用 | **英語検索「kyoto cafe」等での露出用** |
| 写真 | 複数枚OK | **1枚目のみ反映・横長にトリミングされる** |
| 鮮度 | 時系列 | 新しい投稿が上位表示される |

**結論：1行目にキーワード（エリア＋カテゴリ＋商品）を必ず入れる。おしゃれなフックは2行目以降。**

## 1. 投稿頻度：3日に1回（月10本）

Googleの最新情報は新しい投稿が上位に出るため、3日サイクルなら常に新しい投稿がマップ上に表示され続ける。
週3本に増やす必要はない。**3日に1回を止めずに続けることが最優先。**

## 2. 改訂版フォーマット

```
【1行目】絵文字 + 京都・四条烏丸 + カテゴリ + 商品名　← Google検索用。必ずこの順
【2行目】英語の見出し（Keyword in English）　← 英語検索用
【空行】
【日本語本文】2〜3行
【空行】
【英語本文】2〜3行
【空行】
📍 店舗情報
【空行】
・・・
#ハッシュタグ
```

**ポイント**
- 1行目と2行目で「エリア＋業態＋商品」を日英両方押さえる → Googleの日本語検索・英語検索の両方に引っかかる
- ハッシュタグの前に「・・・」を入れて本文と分離 → Google最新情報での見栄えが崩れない
- 価格は必ず入れる（Googleから来る人は比較検討中。価格不明は離脱要因）

## 5. 写真ルールの追加（Google連携のため）

既存の撮影ルール7項目に、以下2項目を追加：

```
8. 1枚目が最重要。Googleの最新情報には1枚目しか反映されない
9. 被写体は中央に寄せる。Google側で横長にトリミングされるため、
   端に寄せると料理が切れる
```

## 6. 五条プリマ（Kyoto Prima Gojo）への展開

四条烏丸が3日に1回のサイクルで2ヶ月回ったら、同じ型を五条に展開する。

五条向けに差し替えるキーワード：
- エリア：「京都・四条烏丸」→「京都・五条」
- 業態：「カフェ＆バー」→「テイクアウト専門パティスリー」
- カテゴリ例：姫ドールケーキ／ホールタルト8ピース／季節のタルト
- 英語：`Patisserie in Kyoto (Gojo)` / `Takeaway Cake Shop in Kyoto`

**先に四条で型を固めてから展開する。2店同時スタートは両方止まる。**
